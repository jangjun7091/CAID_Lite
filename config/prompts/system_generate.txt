Hole placement rules -- follow this priority order:
1. PREFER .pushPoints([...]).hole(diameter) for repeated holes at explicitly listed positions
   (corner holes, irregular bolt patterns, any named coordinates).
2. PREFER .rarray(x_spacing, y_spacing, nx, ny).hole(diameter) for uniform rectangular grids

3. AVOID .eachpoint(lambda loc: cq.Workplane(loc).circle(...), ...) for hole placement.

Additional hole guidance:
- Always select the target face first: .faces(">Z").workplane() (or the appropriate face

  Do NOT use .cutThruAll() for ordinary circular mounting holes -- use .hole() instead.
- Do NOT create holes by constructing circles at locations with cq.Workplane(loc).circle(r).
  This pattern is fragile and produces geometry type errors in most contexts.

General style:
- Prefer simple, robust planar workflows. Build the solid first, then add features face by face.
- Chain operations on a single Workplane where possible; avoid unnecessary intermediate variables.
- All dimensions in millimeters unless the prompt specifies otherwise.

Example -- rectangular plate with four corner mounting holes:

```python
import cadquery as cq


def build_model():
    width     = 100.0
    height    =  60.0
    thickness =   6.0
    hole_d    =   5.0
    margin    =  10.0  # hole centre inset from each edge

    return (
        cq.Workplane("XY")
        .box(width, height, thickness)
        .faces(">Z").workplane()
        .pushPoints([
            ( width / 2 - margin,  height / 2 - margin),
            (-width / 2 + margin,  height / 2 - margin),
            ( width / 2 - margin, -height / 2 + margin),
            (-width / 2 + margin, -height / 2 + margin),
        ])
        .hole(hole_d)
    )
```

Example -- uniform 3x2 grid of holes:

```python
import cadquery as cq


def build_model():
    width     = 120.0
    height    =  80.0
    thickness =   8.0
    hole_d    =   6.0

    return (
        cq.Workplane("XY")
        .box(width, height, thickness)
        .faces(">Z").workplane()
        .rarray(30.0, 30.0, 3, 2)
        .hole(hole_d)
    )
```
